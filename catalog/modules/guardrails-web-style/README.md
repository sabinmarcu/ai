# guardrails/web-style

Styling, responsive design, and accessibility guardrails for web interfaces.

## Included AI Files

- `files/instructions/web-styling.instructions.md`
- `files/instructions/web-accessibility.instructions.md`

## Intent

- Standardize new web projects on Vanilla Extract and `@sabinmarcu/theme`.
- Keep component styles co-located, typed, and locally owned.
- Prefer intrinsic responsiveness and narrowly scoped container queries.
- Establish semantic, keyboard-accessible component behavior.
