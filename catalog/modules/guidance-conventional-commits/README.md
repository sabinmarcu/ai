# guidance/conventional-commits

Universal commit-authoring guidance based on Conventional Commits.

## Included AI Files

- `files/instructions/conventional-commits.instructions.md`

## Intent

- Require Conventional Commits in every repository through `global/core`.
- Provide general type, scope, subject, body, and breaking-change guidance.
- Leave repository-specific scope vocabularies to specialized guidance mixins.
- Remain independent of any enforcement tool.
